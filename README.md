🛒 Blinkit Sales Analysis

📌 Project Overview

A Python-based Exploratory Data Analysis (EDA) project to analyze Blinkit sales performance and identify sales patterns across products and outlets.

🎯 Objectives

1.Analyze overall sales performance
2.Identify top-performing item types
3.Compare sales by fat content
4.Analyze sales by outlet size and location
5.Understand sales trends by outlet establishment year
6.Calculate key business KPIs

🛠️ Tools & Technologies

Python
Pandas
Matplotlib
Seaborn
Jupyter Notebook

🔍 Analysis Performed

Data cleaning and standardization
KPI calculation
Exploratory Data Analysis
Sales analysis by item type and fat content
Outlet-wise sales analysis
Data visualization

💡 Key Insights

The analysis identifies important patterns in sales across product categories, fat content, outlet size, outlet location, and establishment year, helping businesses understand sales performance and make data-driven decisions.
